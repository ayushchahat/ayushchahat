### 🛒 FlashCart — Distributed Systems Architecture Lab
> Microservices backend solving the dual-write problem under high-concurrency order loads

- ⚛️ Implemented the **Transactional Outbox Pattern** for atomic consistency between MySQL & RabbitMQ
- 🔄 Built automated Relay Worker with idempotent consumers and manual ACK/NACK flows
- 📊 Real-time WebSocket dashboard visualizing distributed message flow & live system recovery
- 🐳 Fully containerized via Docker Compose (MySQL + RabbitMQ + multiple Node.js workers)

### 💊 MediChalo — Hyperlocal Medicine Delivery Platform
> Full-stack MERN app with three role-based portals and live delivery tracking

- 👥 Customer, Pharmacy & Delivery Partner portals with dedicated dashboards
- 🗺️ Real-time order tracking via **Socket.io + Leaflet.js** with live geolocation
- 🔐 JWT multi-role auth + **Stripe API** for PCI-compliant payment processing
- 🌐 Scalable RESTful APIs ensuring consistent state across all three portals
